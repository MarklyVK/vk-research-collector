# Промпт для ручной классификации групп VK

Ты классифицируешь сообщества VK для научного исследования.

Я приложу JSON-файл с группами.

Нужно определить, относится ли каждая группа хотя бы к одной области:

## Метки

### `food_delivery`

Доставка еды, продуктов, готовых блюд, рационов, ресторанная доставка и кейтеринг.

Не включай программное обеспечение для ресторанной доставки, если компания сама не оказывает услуги доставки.

### `customer_acquisition`

Привлечение клиентов, реклама, маркетинг, лидогенерация, SEO, SMM, продажи, CRM, call-центры и обучение по этим направлениям.

### `tender_support`

Тендеры, государственные закупки, торги, аукционы, сопровождение, обучение, электронные площадки, банковские гарантии и юридическая помощь.

### `food_service`

Действующее кафе, ресторан, кофейня, столовая, пиццерия, пекарня-кафе, бар или другое
заведение, которое непосредственно готовит и продаёт готовую еду или напитки
посетителям. Не включай магазины, поставщиков, оборудование, каталоги, вакансии,
рецепты, агентства и самостоятельные сервисы доставки без собственного заведения.

## Правила

1. Главный источник решения — поле `description`.
2. Затем используй `name` и `status`; пустое описание требует особенно консервативного решения.
3. `matched_keywords` — только вспомогательный сигнал, одного совпавшего слова недостаточно.
4. Группа может иметь несколько меток.
5. Не используй информацию, которой нет во входном JSON.
6. Верни только валидный JSON без Markdown и пояснений.
7. Сохрани исходный `batch_id`.
8. Включи все группы из входного файла.
9. `confidence` должно быть числом от 0 до 1.
10. Ресторан с собственной доставкой получает `food_service` и `food_delivery`.
11. Агрегатор доставки без собственного заведения получает только `food_delivery`.

## Формат ответа

```json
{
  "batch_id": "исходный batch_id",
  "results": [
    {
      "vk_id": 123456,
      "approved": true,
      "labels": ["food_delivery"],
      "confidence": 0.95
    },
    {
      "vk_id": 654321,
      "approved": false,
      "labels": [],
      "confidence": 0.91
    }
  ]
}

Также можно вручную создать упрощённый файл:

{
  "batch_id": "исходный batch_id",
  "approved_group_ids": [
    123456,
    789012
  ]
}
