# Privacy и минимизация данных второго этапа

Сбор ограничен публичными данными официального VK API. HTML scraping и скачивание
медиа запрещены. Токены читаются из read-only mount, не сохраняются в PostgreSQL и
маскируются в диагностике.

Для пользователя сохраняются только VK ID, имя, фамилия, screen name, признаки
закрытого/деактивированного профиля и технические UTC timestamps. Не сохраняются
телефон, email, адрес, родственники, взгляды, религия, сообщения и бинарные фотографии.
Для вложений сохраняются только нормализованные метаданные; сырой VK JSON отсутствует.

Операционные команды:

```bash
docker compose run --rm collector privacy inspect-user VK_ID
docker compose run --rm collector privacy inspect-group VK_ID
docker compose run --rm collector privacy delete-user VK_ID --confirm
```

Удаление пользователя выполняется одной транзакцией. PostgreSQL `ON DELETE CASCADE`
удаляет memberships/subscriptions, ссылающиеся на пользователя; при любой ошибке вся
операция откатывается. Перед реальным удалением обязателен проверенный backup. В
разработке удаление реальных пользователей не выполняется: rollback проверяется на
изолированной integration fixture.

Backup и exports считаются чувствительными runtime-артефактами, исключены из Git и
должны храниться с минимальными правами. Retention для диагностической таблицы
`collection_job_errors` задаётся операционно; автоматического удаления основных
исследовательских данных нет.
