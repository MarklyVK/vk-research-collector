# План реализации

1. Создать типизированный Python-каркас и конфигурацию из окружения.
2. Спроектировать нормализованную PostgreSQL-схему и Alembic-миграцию.
3. Реализовать устойчивый VK-клиент, пул токенов и возобновляемый поиск.
4. Реализовать фиксированные пакеты экспорта и транзакционный импорт.
5. Добавить русскоязычный CLI, статистику и безопасную заглушку сбора.
6. Подготовить Docker Compose, CI/CD и эксплуатационные скрипты.
7. Покрыть критические сценарии unit-, integration- и smoke-тестами.
8. Выполнить все проверки из `AGENTS.md` и зафиксировать результаты.
