# Handoff: VK API и поиск

Реализованы типизированный асинхронный клиент VK, безопасный пул токенов и
возобновляемая оркестрация поиска. Реализация БД намеренно не включена.

Для интеграции слой persistence должен реализовать `SearchPersistence` из
`vk_collector.search.service`. `save_page` обязан атомарно выполнить upsert групп,
связей с исходным `Keyword` и checkpoint `next_offset`. Завершённые пары
«ключевое слово + тип сообщества» возвращаются через `is_keyword_complete`, что
исключает повторный сетевой запрос после перезапуска.

`VKClient` принимает настроенный `httpx.AsyncClient`, поэтому fake transport и
настройки Docker не требуют изменения клиента. Версия API, таймаут, частота и
путь файла токенов передаются композиционным корнем приложения.
