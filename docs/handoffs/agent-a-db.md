# Handoff: архитектура и PostgreSQL

Добавлены async engine/session, ORM-модели, начальная миграция и описание схемы.
Пакет импорта должен использовать `database.models` и одну транзакцию `session.begin()`.
Для миграции требуется `DATABASE_URL`; создание `vk_reader` с секретным паролем остаётся
за инфраструктурным bootstrap, миграция безопасно выдаёт права уже существующей роли.
