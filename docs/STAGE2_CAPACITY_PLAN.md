# План ёмкости второго этапа

## До pilot

Известно 12 260 целевых approved-групп. Ни число доступных постов/участников, ни
кардинальность уникальных пользователей заранее не считаются измеренными. Поэтому
следующая формула — бюджет и safety gate, а не финальный прогноз:

```text
data = groups*bytes_group
     + posts*bytes_post + attachments*bytes_attachment
     + memberships*bytes_membership + users*bytes_user
     + subscriptions*bytes_subscription
total = data * index_factor + WAL_and_migration_reserve
```

При лимите 200 теоретический верхний предел постов — 2 452 000. При pilot-лимите 1000
верхний предел memberships — 12 260 000, но запуск полного такого объёма запрещён до
измерений. Subscriptions по умолчанию выключены. На индексы закладывается измеряемый
коэффициент, а на WAL/миграции — не менее 30% от измеренного heap+indexes.

## Измерение

На детерминированном pilot фиксируются размер БД и таблиц до/после, rows каждого типа,
`pg_total_relation_size`, число API-запросов, retries, private/skipped, длительность и
уникальные users. Средние bytes/row считаются как прирост relation size / прирост rows;
для sparsity используются также median и p95 по группам. Full estimate масштабируется
по меткам и multi-label без двойного счёта групп.

## Gate

Разрешённый прогноз с индексами и резервом должен быть не более 7 GiB из 10 GiB.
Текущий свободный диск также проверяется. Выше порога последовательно уменьшаются posts,
отключаются subscriptions и ограничиваются members. На 85% запрещаются новые тяжёлые
jobs, на 95% run немедленно приостанавливается. Фактические результаты записываются в
`exports/stage2-pilot/capacity-estimate.json` и заменяют этот предварительный раздел.

## Измеренный результат 28.07.2026

Pilot 35 групп увеличил БД с 85 777 431 до 117 513 239 байт. Получено 3 969 постов,
7 261 вложение, 12 316 memberships и 12 285 пользователей. Прогноз с коэффициентом
1,30 — 14 537 357 656 байт (13,54 GiB), поэтому gate не пройден. Full run оставлен в
`paused_capacity_limit`. Для следующего pilot установлены консервативные кандидаты
posts=100, members=200, subscriptions=false; они не считаются разрешёнными до нового
фактического измерения.
